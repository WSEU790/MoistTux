NEXUS — AI-powered Linux infrastructure command center

Start NEXUS from the Start menu or the desktop shortcut.

Add a Linux server: Fleet -> Add server -> Install over SSH.
Local AI: install Ollama from https://ollama.com and run "ollama pull qwen2.5:7b".

NEXUS checks for updates automatically and installs them the next time it
starts (Settings -> Updates). Your data lives in %LOCALAPPDATA%\NEXUS and is
kept across updates.
